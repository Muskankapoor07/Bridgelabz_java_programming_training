# Object Oriented Programming (OOP)

## Overview

This repository contains Java programs and projects developed as part of the BridgeLabz Java Training Program. The focus of this module is to understand Object-Oriented Programming principles and apply them to real-world applications using Java.

The programs demonstrate the use of classes, objects, inheritance, polymorphism, abstraction, encapsulation, interfaces, and other advanced OOP concepts.
