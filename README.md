# Core Programming

## Overview

This repository contains Java programs and practice problems completed as part of the BridgeLabz Java Training Program. The objective of this module is to build a strong foundation in Java programming by understanding programming fundamentals, problem-solving techniques, Java architecture, arrays, strings, methods, exception handling, and software development best practices.
